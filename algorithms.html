Start here: 2-Look Last Layer

Full CFOP uses 78 algorithms for the last layer. Most cubers start with 2-Look: only 16 algorithms, done in 4 steps. Learn these first, then move on to full OLL and PLL.

OLL: Orient the Last Layer

One algorithm makes the whole top face one colour. The cases are grouped by the shape the top colour makes, which is how you recognise them.

PLL: Permute the Last Layer

The top is already one colour; one algorithm moves every piece to the right spot. Look at the sides of the top layer to recognise the case, for example "headlights", which are two matching corners on one side.

Drill: can you recognise it?
